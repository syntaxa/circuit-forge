# Circuit Forge

Приложение для домашних круговых тренировок и база упражнений с поясняющими иллюстрациями.

## Language

**Иллюстрация упражнения**:
Изображение, которое помогает узнать упражнение и дополняет текстовое описание его выполнения.

**Характерная поза**:
Один момент упражнения, показывающий его отличительную часть. Для составного движения такая поза может передавать только одну из его фаз.

**Референс стиля**:
Образец, задающий внешний вид персонажа, одежду, палитру и оформление иллюстраций; поза и ракурс могут отличаться.

**Согласованная поза**:
Характерная поза упражнения, которую пользователь подтвердил для изображения. Согласование позы не означает принятия готовой иллюстрации.
