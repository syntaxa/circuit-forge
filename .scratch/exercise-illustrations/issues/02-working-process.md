## Question

Из обратной связи на пробу: пользователь хочет подтверждать выбранную позу каждого упражнения перед генерацией. Учитывать это как обязательную контрольную точку процесса; согласование позы и принятие готовой иллюстрации — разные действия.

Какой минимальный процесс создания иллюстрации принять на основании пробы: какие данные и референсы подавать, как выбирать и проверять позу, когда исправлять промпт или допускать две фазы, и по каким признакам принимать результат?

Обсудить с пользователем примеры и фактическое количество исправлений из билета «Подходит ли генерация одной характерной позы с общим референсом». Решить, достаточно ли доказательств для завершения поиска подхода или нужна ещё одна конкретная проверка. Итог должен позволить отдельно обсуждать раскатку, без реализации пакетной генерации в этом билете.

## Comments

Подготовлен [проект процесса](../process-draft.md) на основании принятых трёх иллюстраций. Сохраняется работа через встроенный image_gen в текущем чате и исходный 1.png. Контрольные точки: индивидуальное подтверждение позы до генерации и отдельное принятие результата после неё.

Открыта одна пользовательская развилка: согласовывать позы небольшими наборами (рекомендация — пять упражнений) или проходить весь цикл по одному. Полная раскатка остаётся за границами этой карты. До ответа пользователя билет не разрешён.

## Answer

Пользователь выбрал «по 5». Принят [процесс](../process-draft.md): согласование поз каждого упражнения наборами по пять → генерация только согласованных поз со стабильным исходным референсом → проверка и отдельное принятие каждой иллюстрации. Для правок повторяется только затронутое упражнение. Одна поза по умолчанию, исключения обсуждаются отдельно. Отдельный скрипт для начала работы не требуется; дополнительных проверок перед применением процесса пользователь не запросил.

Карта выбора подхода завершена. Подготовка следующих наборов — дальнейшее применение согласованного процесса, а не дополнительный билет этой карты.
