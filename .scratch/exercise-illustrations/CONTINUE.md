# Продолжение работы над иллюстрациями Circuit Forge

Состояние сохранено 5 ноября 2026 года. Этот файл — точка входа для продолжения на другом компьютере. Все изображения и промпты лежат в репозитории; доступ к прошлому чату и каталогу .codex/generated_images не требуется.

## Цель и согласованный способ работы

Нужно создать недостающие иллюстрации упражнений из constants.ts в стиле public/exercise-images/1.png. Сначала проверили подход на трёх упражнениях; проба принята, карта wayfinder завершена. Теперь применяется согласованный [процесс](process-draft.md).

- Работать наборами по пять упражнений.
- Для каждого упражнения сначала предложить по-русски фазу, конкретную позу, точки контакта и ракурс. Пользователь подтверждает позу до генерации.
- После подтверждения составить промпт из общего блока стиля и индивидуального блока позы. Использовать встроенный image_gen с исходным 1.png как референсом при каждом вызове. Отдельный API-скрипт не нужен.
- Сохранять персонажа, одежду, палитру, голубой фон с кругом и рамкой. Ракурс подбирать под упражнение. По умолчанию одна поза; две фазы только после обсуждения.
- После генерации показать результат и сравнение в размере карточки 280 × 280. Принятие картинки пользователем — отдельный шаг, не равный подтверждению позы.
- Хранить точные промпты, версии и статус каждого упражнения. Не генерировать повторно принятые картинки. Не перезаписывать существующие иллюстрации автоматически.
