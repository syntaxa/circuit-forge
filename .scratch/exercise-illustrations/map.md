# Найти простой рабочий подход к иллюстрациям упражнений

Labels: wayfinder:map
Status: resolved

## Destination

Выбрать подход к созданию недостающих иллюстраций и проверить его на трёх разных упражнениях. Результат карты — согласованный по итогам пробы процесс и понимание его ограничений, достаточные для отдельного решения о раскатке на всю базу.

## Notes

- Пользователь: сначала найти работающий подход, затем думать о раскатке на всю базу.
- Уточнение пользователя после пробы: выбранную позу каждого упражнения требуется подтверждать до генерации. Для Lunge Touch And Kick выбрана нижняя точка: заднее колено и рука касаются пола; рука со стороны передней ноги, как указано в шагах.
- Исходная гипотеза: название, описание и шаги упражнения позволяют выбрать одну характерную позу и составить промпт; изображение-референс задаёт стиль.
- Согласовано в обсуждении: сохранять персонажа, одежду, палитру и фон образца; менять ракурс под упражнение. Начать с одной позы; две фазы рассматривать как исключение, если одной недостаточно.
- Референс: [1.png](../../public/exercise-images/1.png). Источник упражнений: [constants.ts](../../constants.ts).
- Проба: Chair Dip, Diamond Push-Up, Lunge Touch And Kick — опора на предмет, читаемость положения рук, составное движение.
- Начальная среда для пробы — этот чат Codex; отдельный скрипт пока не требуется. Это стартовый вариант, пригодность которого предстоит проверить.
- Иллюстрация в существующем интерфейсе квадратная, максимум 280 × 280 CSS-пикселей. Важна читаемость в этом размере.
- Карту ведём по wayfinder; при работе над решениями использовать prototype либо grilling и domain-modeling. При генерации использовать imagegen. Оценку человеком не заменять выводом агента.
- Трекер — локальный Markdown: дочерние файлы в issues/, Status: open / claimed / resolved; Blocked by ссылается на номера файлов. Перед работой помечать билет claimed; ответ записывать в его Answer, затем закрывать и добавлять ссылку ниже. Первый доступный билет определяется по номеру.
- Прототипы сохранять отдельно от public/exercise-images до их принятия пользователем. Существующие иллюстрации не перезаписывать.

## Decisions so far

- [Подходит ли генерация одной характерной позы с общим референсом](issues/01-pilot.md#answer) — все три иллюстрации приняты; четыре генерации, включая смену фазы Lunge; требуется подтверждение позы до генерации.
- [Какой процесс принять по результатам пробы](issues/02-working-process.md#answer) — позы согласуются наборами по пять; далее генерация с общим референсом и отдельное принятие каждой картинки.
